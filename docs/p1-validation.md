## 本次发现并修复

1. JSON布尔字段原先按真值解释：字符串“false”可能发动技能。现在严格验证命令字段与开局随机注入类型，非法输入保持原状态。
2. publicView原先缺少当前攻击/移动信息，部分对象引用原状态。现在提供公开攻击、目标、顺序、移动及已使用次数，并深拷贝；不暴露牌堆、随机输入或他人手牌。
3. 新页面载入旧记录后，本地命令编号可能重复。现在跳过已接受编号，浏览器导出记录证实正常续接。
4. 同一文件重复选择可能没有change事件。现在每次读取后清空文件输入，允许再次载入。
5. 页面原先仅显示弃牌数、待攻击信息不完整。现在可查看公共弃牌，响应期间显示攻击信息，已结算攻击的公开日志也保留目标。

前次修复：系统window.confirm在内嵌浏览器中的控制超时，改为页面内确认框。
