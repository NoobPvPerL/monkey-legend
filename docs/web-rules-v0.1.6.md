# web-v0.1.6：阶段三完整规则

应用0.2.4-p2.5，数据库schema2／engineRevision16。仅新开局使用；web-v0.1.1—v0.1.5旧局继续原规则。内容为16角色、23种85实体牌；原64张保留，新增11种21张。以下是负责人批准的网页版执行规则，原始牌面与来源文档不改写。

## 开局与选角

四人，各自为战或双人同盟。数据库独立随机选择S1—S4之一先手，按该行动顺序逐人三选一，每次30秒；超时从本次候选随机选。选中角色全桌移出、未选两张归还，已选公开；候选只有本人和鉴权观众可见。四人选完后才分配出生格、发牌、启动个人回合。选角期间保留房间码、成员、matchId和原截止时间，断线继续计时。

2v2先分机械猴子／帝汶家族。应豪和猴N属于机械猴子，X帝汶与lemon属于帝汶家族，其余中立。中立同时进入两队候选池，选中后归属该队；当前可玩角色池为机械12名、帝汶15名，角色全桌不重复。各自为战独立计队，家族与越水能力仍分别判断。lemon为帝汶随从，出生／复活在操场。固定出生地区有多个空格时随机分配，玩家不重叠。

组合按打出时本局队伍累计，全局不清；转换材料不按原牌累计，反制不累计。拥有组合能力的角色须存活且仍属该队，死亡暂停、复活恢复；全链结算后自然胜利优先，再判组合，同时满足双方为平局。

## 必要新牌与装备

- 猴子游戏：2AP，同／相邻地区1—3敌人分别d6，单数伤1，始终群体。应豪例外如上。
- 咖啡：0AP，+8AP，跳过下一次整轮AP补充及下次个人开始跑者／尚德荟加点；重复只刷新，头锤等牌收益照常。
- 橡胶：依牌面费用、合法位置交换执行，角色免疫、装备禁水及主动位移限制继续生效。
- 紫檀木：1张，其余新增每种2张。d6费用按实体牌／个人回合锁定，先展示后确认支付，取消不重掷；可复活自死亡尚未跨过一个完整个人回合结束的角色，1HP、0AP、空手、固定出生地区随机空格，无格不可用。
- 阿萨姆：治疗自己及同／相邻地区存活队友，各自为战仅自己。
- 装备：手部2件、坐骑1件，同名不重复，仅装配时明确选替换，不开放主动卸装。旧装备失去效果先结算，再装新装备；死亡先淘汰、弃全装备，无治疗／传送救活。
- 面包：自由行动2AP指定全图其他存活者，下次个人回合不能主动出牌，移动／技能／响应／弃牌仍可；不叠层，到自己第二次个人开始才可再次用。失去可10秒选回2HP。
- 哈基米：即使帝汶原生也不能进水；失去可10秒选山洞空格传送。
- 等一羊：首个人回合无加成，上次个人回合未用基础移动则本次可移两次，各自独立完整d6。
- 小白马：自己结束且本回合无任何主动位移，令其他有坐骑者至自己下次开始不能主动位移；携带装配时来源和技能修改，死亡清除。
- 勿一羊：基础移动免费，次数、步数和落点规则照常。
- 粥盛羊：每次正数治疗直接回满，不超过生命上限；学子食物免疫先判断。

## 沿用补丁与计时

攻击牌不限制每回合张数。每次成功出牌立即重置60秒，选择暂停主钟、各自独立计时；弃牌20秒，响应／水域／技能通常10秒，选角30秒。基础移动结束扣费，未走可取消免费但次数已使用，走过结束或超时扣费。

轰炸标记保留上次结算轮次，非预告。山洞永久免毒／轰炸；其他11区每轮新增2区永久毒（最后1区）；全部变毒前教学楼／操场／办公室免毒免轰炸，此后加入旧室外轰炸池、永久不毒。山洞每连续3次自己的个人回合结束，扣至多2AP和可被护盾挡的1HP；离洞立即清零，同洞换格不清。躲避球不能被防御姿态响应。
