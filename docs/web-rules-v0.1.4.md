状态：2026-10-17本地候选，负责人在本会话批准阶段2，并在问题复述后回复“全部同意”。属于网页版裁定，不覆盖原始牌面。尚未推送或部署。

本版叠加[web-v0.1.3](web-rules-v0.1.3.md)及其继承规则；本文有明确变化时以本文为准。当前仍为4人FFA或随机2v2、跑者／lemon／美丽学子／土豆、已实现12种64实体基础牌。三选一、新增12角色、完整76种牌、装备／坐骑及复活效果在后续阶段，未放入可玩池。攻击牌不限张数，成功主动出牌立即重置60秒；手牌上限弃牌20秒，水域弃牌另计10秒。

## 地图与出生

经典地图使用[原始CSV](maps/classic-regions.csv)的4×8布局。角色固定出生地区：跑者在高唐农场、lemon在操场、美丽学子和土豆在教学楼；由数据库从该地区空格随机分配，不重叠，不再要求跨地区随机或互不相邻。

lemon属于帝汶家族的随从，适用帝汶水生类别；出生及所述复活地区保留操场。“半个帝汶”不产生0.5伤害、半额费用或胜利权重。本版未增加复活触发或复活血量。

## 地点

| 地点 | 规则 |
|---|---|
| 高唐农场 | 首轮无常规摸牌，不加；之后个人回合开始的常规摸牌额外+1，技能／食物摸牌不加 |
| 操场 | 从这里开始基础移动免费，0AP可开始；从外面开始的移动仍按原规则结费；仍每个人回合一次、掷骰取得1—3步 |
| 尚德荟 | 首轮不加；之后个人回合开始+1AP，跑者先补到6再加1 |
| XDF | 食物总治疗+1，不超过上限；角色限制优先，美丽学子仍不因食物回血 |
| 飞船 | 本人、无选择窗口的行动阶段、至少1AP；每个人回合一次，去任意空格，实际不扣AP，不占基础移动次数；入水照常处理 |
| 通校 | 本人、无选择窗口的行动阶段、至少1AP；耗尽现有AP去空的云上学府，不占基础移动次数 |
| 教学楼／秀松苑 | 位于其中的使用者不能用躲避球／猴子游戏；不因此保护这里的目标 |
| 办公室 | 位于其中的目标在出牌时免受建民效果；与禁止指定目标分别处理 |
| 山洞 | 正常步行进入立刻结束移动；被占用时不能进入或穿过；环境豁免；传送不受虚构的“途经山洞”影响 |

飞船／通校先点按钮，再点高亮空格；选择落点前可以取消。所有落点、费用、次数及阶段由数据库重验，客户端不决定结果。

第5整轮开始农场封闭：原住可留、可离开，后续移动／传送不能进入，仍可被轰炸。其他尚未实现的强制移动牌在后续接入同一进入检查，不能绕过封闭规则。

## 水域

- 红素洋、淘安泽是水域。普通进入每格消耗2步。
- 非水生每次从陆地进入一个连续水段，自选弃1张手牌；连续水内移动不重复，离水再入重新弃1。传送入水同样处理；没有手牌免费。
- 每整轮开始，仍在水域的非水生再弃1。沿行动顺序处理，然后普通整轮AP补充，再刷新毒区，之后开始首个存活玩家的个人回合。
- 水域弃牌10秒；超时由数据库弃手牌实体ID最小的一张。水域选择暂停个人行动预算，保留待续移动；刷新／重连不重置窗口，重复提交不重复结算。与20秒手牌上限弃牌分别计时。
- 帝汶水生（含lemon）可沿一条直线越过连续水格，整段只耗1步，不在水中拐弯；对岸空陆地可直接落下，对岸被占时可选该对岸格正交相邻的空陆地；无合法落点不能越。正常走进水格仍按普通步耗，水生不交水域弃牌。

当前牌池中的土豆传送仍只去距离≤3的空陆地。完整牌池的强制移动、交换或地形变水尚未实现，不能把本版入水处理宣称为这些卡牌已完成。

## 地区环境与整轮时间线

整轮指所有仍存活玩家各行动一次；跳过已淘汰玩家，不按单个人行动重复刷新。

| 分类 | 地区 |
|---|---|
| 室内8区 | 教学楼、秀松苑、尚德荟、食堂、飞船、XDF、办公室、云上学府 |
| 室外6区 | 高唐农场、操场、帝汶岛、红素洋、淘安泽、樱花大道 |
| 豁免 | 山洞 |

1. 轮初：依次处理水域弃牌，补充普通整轮AP；从第1轮起随机新增2个尚未中毒的室内地区，永久有毒。候选不足2个时全部加入，8区耗尽后不再抽毒区。不提供房主1／2个选项。
2. 玩家各完成自己的个人回合，正常处理响应、技能、手牌上限和淘汰。
3. 轮末：随机抽取2个不同室外地区轰炸，无提前预告；跨轮可重复。按当前所在地区统一结算毒与轰炸，同批伤害、伤后技能和自然胜负检查完成后，再开始下一整轮。

毒与轰炸基础伤害均为1，普通护盾可以抵挡。对同一玩家，在同一地区连续整轮实际失血，伤害依次1、2、4、8……；任何换区立即清零，即使又返回；该轮没有环境伤害、护盾全挡或没有实际失血也中断连续。当前室内／室外分类互斥，不将同地区毒炸相加为两次伤害。

环境不计为玩家击杀，伤后角色技能仍按现有规则触发，淘汰采用同批次结算。取消新版12轮强制结束，按自然存活胜负继续；玩家与观战页不显示“/12”。旧v0.1.1—v0.1.3对局保留原地图、环境绕盾、轮初伤害及12轮规则，结束后同房间可开新版。
