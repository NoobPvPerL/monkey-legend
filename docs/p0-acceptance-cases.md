## 2. 可复现完整推演输入

两模式共用以下输入，仅改变队伍。不使用真实客户端，也不把临时账本视为已经实现规则引擎。
- 座位/首位：S1 lemon、S2美丽学子、S3跑者、S4土豆，首位S1，均在固定出生格。
- 各自为战各为敌人；团战A=S1/S2，B=S3/S4。
- 从64实体中取 basic-009#01—#04 给S4。其余60实体按ID/份号排序，取前12作为S1—S3各4张；初始牌堆顺序为这12张、S4四张、其余48张。后续每次洗弃牌注入按实体ID升序的合法全排列；这是测试输入，不是正式固定洗牌。
- 全员不移动，放弃全部可选额外摸牌、响应与受伤技能。每回合常规补牌照常执行；结束按规则弃牌，S4优先保留上述四张躲避球，其余按ID升序留到上限；其他人按ID升序留到上限。每次先处理抽空再补足。
- 第3—7轮轰炸XDF；第8—12轮轰炸食堂。在上一轮结束预告，均为合法候选且无人站在这两区。

- 个人计时均未超时。本推演不用于估计局长、玩家策略或平衡性。
