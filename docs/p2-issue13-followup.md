- 操作区给出AP不足、目标不合法、旧局次数用完、等待确认、窗口到期等具体原因。请求使用当前身份、对局、版本及选择ID；发现界面过时不悄悄改投另一个窗口。
- 服务端返回明确的过期失败时更新快照并提示“原选择窗口已结束，本次操作未执行；已同步最新状态。”，不自动重发为新操作。结果不确定时仍保留原请求ID及既有幂等恢复机制。
- 简洁提示例如 `S1 [−1 AP] ─搏击操Ⅰ→ S4`、`S4 [AP −1 → 47]`；伤害显示实际失血与护盾抵挡，头锤显示实际AP前后值。完整描述可在日志中切换，未知文案保持原文。
