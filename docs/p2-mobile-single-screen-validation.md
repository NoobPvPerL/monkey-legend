## 页面行为

- 手机主界面使用100dvh及固定区域分配，顶部、行动状态、四名玩家、全部32格、横向手牌、当前操作同时可见。对局页及其主面板没有纵向滚动。
- 普通移动、结束行动及当前确认／响应保留在主操作区。完整技能、地点移动、方向和装备／地区等复杂设置通过“操作与设置”展开。展开、收起及Escape关闭不重置Bob复制／替换等已有选择。
- 主手牌以牌名、费用及简短牌效为摘要，仍左右滑动；“牌效详情”保留完整文本与组合进度。“玩家”保留四人完整生命／AP／护盾／手牌数及公开装备详情。摘要不作为完整牌效，原始牌面未改动。
- “查看全图”继续保留环境完整说明及放大地图。展开详情／设置期间计时照常；长详情可以在独立浮层内阅读，不使主对局页变成长页。
- PC分栏保持。新增ActionPanel在原位置展开，避免把Stage4Controls搬入另一个React子树而丢失表单状态。主图只渲染一份，防止状态不一致。
