## 请重点测试/提出意见

1. 能否解压后一键启动，页面、中文、牌面图是否正常。
2. 各自为战和2对2是否容易理解；四座交接、手牌、目标高亮、确认出牌、响应是否顺手。
3. 四角色技能、AP费用、基础移动、弃牌、60秒/10秒计时是否符合规则及预期。
4. 缩圈/轰炸提示、胜负结果和日志是否清楚；有无卡住、错扣费或无法结束对局。
5. 希望优先改进哪些界面/操作体验，以及准备进入P2前还缺什么。

首版本来只启用四角色、12种64张基础牌；尚无好友联机、神牌/课程或原作全部内容。相关愿望可以提，但请与P1现有功能缺陷分开描述。PR #3和旧已关闭设计Issue本次不处理。
