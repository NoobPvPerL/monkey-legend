# 网页版规则 web-v0.1.3

日期：2026-10-17（Asia/Hong_Kong）。负责人在本会话转述工作室讨论决定并要求实施：删除“每个人回合最多两张攻击牌”的限制。

本文件覆盖 [web-v0.1.2](web-rules-v0.1.2.md) 和 [web-v0.1.1 基线](web-rules-v0.1.md) 中的攻击次数上限；其余规则继续沿用相应版本条款。

## 攻击牌不限次数

- 同一个个人回合可以连续使用第三张、第四张及更多攻击牌，没有统一张数上限。
- 每张仍需支付其 AP 费用，拥有对应手牌实体，并满足行动阶段、目标数量、距离、队伍、嘲讽和免疫规则。AP不足或没有合法目标时不能使用。
- 每张牌独立完成响应、伤害、技能触发及清理后，行动者才能继续下一张。不能在移动、响应或技能选择尚未完成时插入新攻击。
- 搏击操Ⅰ／Ⅱ／Ⅲ仍可选择1—3名不同存活敌人，始终按群体判定；每张付一次费用。
- 攻击计数字段仅记录本回合已出攻击牌数量，不再用于拒绝第三张牌。界面显示“攻击已出N张 · 不限次数”。

## 继承的规则

头锤吸收目标全部现有AP、肘击最多反吸2AP、每次成功主动出牌立即重置60秒、弃牌20秒、一次基础移动及结束扣费、聊天和观战均沿用web-v0.1.2。

## 生效与兼容

升级后新开联机对局及原房间再开使用web-v0.1.3。已经开始的web-v0.1.1／web-v0.1.2对局按其保存的规则完成，界面明确标注旧版限制；不悄悄更改进行中的规则。P1本地复现桌仍用于旧版规格复核。

数据库增量迁移为009_unlimited_attacks.sql，schema仍为2，engineRevision为9。规则变更不代表已经推送GitHub、完成云端迁移或真人验收。

经典地图、随机出生、地点／水域／环境、选角和装备仍等待[Issue #14](https://github.com/NoobPvPerL/monkey-legend/issues/14)的补充，不随本次攻击规则自动启用。
