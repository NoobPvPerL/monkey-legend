## 三、建议开发顺序及交付条件

### 阶段0：冻结规则与内容清单

产物为版本规则、76种牌实体配比表、16角色的阵营／水生类别／出生表、地点及环境时序表。已有字段直接从内容矩阵导入，不要求重复填写；原文缺项或与新裁定冲突的少数参数另建清单，并明确阻塞哪个阶段。

### 阶段1：版本化数据与经典地图基础

- 建立按对局规则版本读取地图、牌池、角色、标签及环境配置的接口。现有TS引擎大量直接引用全局MAP／CARDS／CHARACTERS，SQL也依赖旧catalog，不能只替换CSV或覆盖001_data.sql。
