## N-13 装备哥与共享

- 4HP、操场出生、中立、非水生；原出生容量过滤保持。自己每成功安装一件实体装备，可免费30秒选摸1，超时不摸；被反制／安装失败不触发，替换／转学／壬人心转入的实际安装触发。共享取得使用资格不等于安装，不产生额外摸牌，也不递归共享。
- 同盟模式中，只要本队存在存活中饭，全队共享该队各人的实际装备效果，无距离限制；中饭暂离地图保留共享，淘汰停用，复活恢复。FFA只用自己的装备。队友暂离地图时其实际装备仍可共享；只有在图存活的使用者可发动技能。共享为锁定，不受011封禁新主动技能影响，原装备来源免疫和效果免疫继续检查。
- 实体／成对件只在持有人的装备区，槽位／替换／偷取／Bob复制目标仍检查真实持有人，不因共享扩大容量。相同装备的多件效果分别执行，次数、耐久、冷却、唐车设置均绑原件，全队共用消耗。来源持有者与本次效果使用者分开；角色修饰谱系保留，效果／伤害归本次使用者。装备失去只对真实持有人触发一次。
- 面包冷却按原持有者个人开始次数计算，队友使用也更新同一原件门槛；被偷继续沿已确认的剩余冷却转移，不刷新。手表每名实际使用者记录自己的个人开始格，不能借队友的位置记录传送；同一件本个人回合共用一次使用标记。原件失去／安装时清理共享位置历史；失去共享资格也清理该使用者历史，恢复后重新记录开始格，不能回溯中断前旧坐标。
- 小白马锁与双移动／鞋子、治疗回满等持续效果按共享资格动态检查。禁水坐骑约束每名共享者今后的进入水域；共享新启用不凭空传送已在水域者，原件持有人的安装禁水检查保持。新获得／失去共享刷新基础移动可用次数，不退已消耗费用／次数。
