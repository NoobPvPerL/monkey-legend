# 网页版规则 web-v0.1.2

旧版记录：2026-10-17负责人转述工作室决定取消攻击牌张数上限，最新联机规则见 [web-v0.1.3](web-rules-v0.1.3.md)。下文两张上限仅适用于已开始的本版本旧局。

日期：2026-10-16。负责人批准第二批及 Issue #13 的新增裁定。本文件与 [web-v0.1.1 基线](web-rules-v0.1.md) 共同构成本地候选版规则；下列条款覆盖旧版对应条款，其余规则沿用基线。尚未更新线上应用。

## 移动（覆盖 W-03 费用时点）

基础移动要求至少 1 AP，每个个人回合最多一次。点击移动后由数据库掷骰，立即消耗本回合移动次数，暂不扣 AP。

- 未成功走过任何一步：取消或超时结束，不扣 AP，移动次数不退回。
- 已走至少一步：主动停止、额度耗尽、结束行动或超时收尾时扣 1 AP，仅扣一次。走出后回到起点仍需扣费。
- 经占用格超时回到最近合法空落点；走过就扣费。移动过程中不能出牌消耗 AP。
- 断线和恢复不重置步数或倒计时，费用由数据库结算。

## 卡牌（覆盖 W-04 对应条目）

| 卡牌 | 本版规则 |
|---|---|
| 搏击操Ⅰ／Ⅱ／Ⅲ | 均为全图群体攻击，可选 1—3 名不同的存活敌人，不可选自己或队友；支付 1／2／3 AP，每个目标分别扣 1／2／3 AP，缺口转普通伤害，不转给攻击者 |
| 头锤 | 费用、距离及响应规则不变；将目标结算时的全部现有 AP 转给攻击者。目标此时为 0 AP 则造成 1 点普通伤害 |
| 肘击 | 仍取消头锤，反吸最多 2 AP；攻击者此时为 0 AP 则造成 1 点普通伤害。此次未改变肘击 |

搏击操只选一人仍属群体：不受 lemon 单体嘲讽约束，美丽学子恰一张手牌时不能被选中。各目标按原顺序分别响应，防御仅取消该目标；按一张牌付费，攻击次数计一张，每个人回合最多两张攻击。

## 时限（覆盖 W-09 对应条目）

- 个人行动开始有 60 秒。
- **每次成功主动出牌时立即重置为 60 秒**，包括攻击和补给；未命中或被防御不撤销重置。
- 响应与技能选择仍按原规则暂停或消耗个人预算，不因为响应牌打出而重置主动玩家预算。
- 弃牌窗口独立为 20 秒，其余选择通常为 10 秒；开始／结束额外摸牌仍受剩余个人预算约束。
- 移动、行走、停止、聊天、观战、重复或失败请求均不重置计时。断线继续计时。

## 版本与来源
