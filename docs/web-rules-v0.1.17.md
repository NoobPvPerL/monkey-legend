本批新增007波波鲨鱼、017猴十六、018猴四、019猴五、032痞帅、036水母、051朱鹏岩、052朱伟岩。HP／出生地区、阵营、水生及所有技能规则以负责人逐组批准的[F完整裁定](p3-batch-f-decisions.md)为准；该记录包含全部A／B／C细则及猴五首杀补充裁定，不再保留未决定的运行默认值。来源参照[角色原始转录](cards/角色牌.md)及p3-f-source.json，原始文本不被网页裁定改写。

F的生命变化允许当前HP与有限上限同步减少；零上限死亡不能普通复活，仍有上限但HP归零者保留既有复活窗口。猴五在状态中保留初始2作为结算生命比例的分母，公开显示无有限上限∞；这不限制普通回血增长。首杀临时锁治疗的上限单独记账，首次全局淘汰解除。

坚韧采用暂停的权威伤害队列：先处理角色免疫、装备防护、伤害上限及护盾，再由朱鹏岩在30秒内选择消耗N点上限抵挡N预计失血；不得超过预计实际失血或把上限降到0。上限修正导致的当前HP截断不作为伤害；超时选0，恢复同一份伤害，不重复扣护盾、磨损装备或掷骰。

同批伤害顺序沿既有行动顺序，猴四第一次实际失血存活后立即获得后续免伤，回家位移随后入队；同批后续及环境伤害同样受免伤限制。伤害批次完成后统一执行淘汰清理、首次死亡解锁及既有伤后反应。技能直接淘汰不冒充普通伤害，也不增加伤害统计。

无唐车禁位移和干枯离水均由数据库判定。普通落点、交换、肘击、冲撞、传送及强制路径仍检查占格／封闭地区／装备／免疫；开局、复活、离场返回按裁定豁免。交换和肘击跟进在双方位置改变前判定移动许可；水母冲撞离水失败时不得踏入仍被占用的格，并保留未用基础步数。位移链判定和地区进入触发沿E批根链记账，避免同链重复。

技能及选择不刷新60秒；角色判定／目标／坚韧窗口30秒、技能弃牌20秒。客户端只提交技能、实体牌、目标、选择点数等意图，不能提交骰子、伤害结果、HP／上限或权威队列。

出生容量过滤继续生效；地图、角色出生地区、四人FFA／2v2不变。G／H及大帝汶008未进入本版；神牌与课程仍属P4，人数和主题色另批。
