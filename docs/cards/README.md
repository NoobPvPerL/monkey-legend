## 统一格式

每种牌使用同一结构：稳定 ID 标题 → 字段表 → `能力文本（牌面）` → `用户补充` → `待确认与转录备注`。本次 ID 一经登记固定保留，后续新牌另分配新 ID，不因排序、改名或插入牌重新编号。

| 字段 | 保存方式 |
|---|---|
| ID | 基础牌 `basic-001` 至 `basic-076`；角色牌 `character-001` 至 `character-053`；神牌 `god-001` 至 `god-016`；课程 `course-001` 至 `course-008` |
| 名称、类别、子类 | 名称按牌面，类别按原素材目录；基础牌继续区分攻击、防御、锦囊、食物、武器槽和坐骑 |
| 牌面词条 | 按基础牌顶部词条记录；其他类别未印词条则为不适用，不用角色名代替词条 |
| 阵营 | 角色/神牌未明确印出阵营，记“未注明”；不凭出生地、名字或阵营牌背反推完整归属表 |
| 牌面血量、出生地 | 记录数字、`?`、`???` 或“未注明”；牌面血量不自行推导为最大生命值 |
| 牌面行动点 | 固定值/变量/多档值原样记录；角色的费用见具体技能正文，未写出的费用仍未注明 |
| 范围、对象/牌面标签 | 保留“相同/相邻区域”“全地图”“单体伤害”等原表述，治疗牌也不改掉印出的伤害标签 |
| 冷却时长 | 保存课程的“一回合”“二回合”“无”；未印出的记未注明，不自动补默认值 |
| 来源图片、原始文件（工作区） | 来源链接指向仓库素材；另保留工作区原始相机/微信文件名；课程增加对应插画链接 |
| 转录状态、规则状态 | 已对照图片转录；完整裁定仍待确认。不是实现状态或可用牌池声明 |

`未注明` 表示图片缺失该信息；`不适用` 表示这个类别没有该类牌面字段；`见能力文本` 表示分技能的数值不能合并为单一属性。不能把这些文字转换成 0、免费、无限、默认出生地或默认阵营。

能力正文保留所有技能，包括主动技、锁定技、被动技和神的陨落，以及课程的小字补充条款。多条能力分项列出，整理换行、标点及编号；不依据“通常玩法”改写技能类别、删掉矛盾条款或补规则。遮蔽名称中的星号原样保留；个别缺少技能名称的条目用“未命名”标记。

## 来源与当前会话补充

- 主要来源为 `assets/cards/基础牌/`、`角色牌/`、`神牌/`、`选修课/` 的图片；直接读图转录，OCR 仅辅助查漏与对照，不直接作为最终文本。
- 仓库图片和工作区同类别的原始图片按 SHA-256 逐一匹配，确认全部 170 张都有对应原图；转录条目保留原文件名。
- [咖啡](基础牌.md#basic-015)和[橡胶](基础牌.md#basic-016)的素材文件名使用“帝汝”，牌面顶部词条为“帝汶”；登记时按牌面记词条，图片文件名没有改动。
- 用户于 2026-10-14 要求多档和负数行动点费用先保留牌面写法。因此 `/` 或 `1-6` 不自动解释为掷骰、任选或某个默认数值，负数不自动解释为获得行动点。
- 用户于 2026-10-14 明确 [LMM](基础牌.md#basic-026) 的“若此作”意为“如果这样做”；强制选中的完整范围仍未另外裁定。
- 用户于 2026-10-14 确认[南帝汶](角色牌.md#character-030)的同步方向：对方扣血/回血同步到南帝汶，南帝汶的回血同步到对方，南帝汶的扣血不影响对方。原文保留，解释列在用户补充中。
- 用户于 2026-10-14 要求[朱伟岩](角色牌.md#character-052)和[水母](角色牌.md#character-036)的缺失参数先标“未注明”；已在[开发方案](../网页游戏开发方案.md)登记。

总规则和历史来源以 [rule.md](../rule.md)、[rule-decisions.md](../rule-decisions.md) 为准。若牌面、总规则、成员回复、用户补充存在冲突，保留各来源并请求裁定，不自动决定优先级。

开发 agent 还需结合总规则确认以下通用事项：

- “回合”“一轮”“下回合”的具体时点；抽牌、加点、环境、冷却和每轮次数的刷新。
- 行动点与手牌上限、结转、溢出、卡牌实体份数、摸牌不足与牌堆抽空。
- “格”“地块”“区域”“地区”的映射、相邻是否含斜角、距离单位、传送/强制移动/越界和占位。
- 判定骰子与概率、指定/重掷/拼点、平手、费用支付及响应先后。
- “最高等级”、免疫、无视、真伤、扣血、护盾、反伤、易伤与天道伤害的关系和结算顺序。
- 生命上限改变、无上限角色、百分比与小数取整、致命伤害、救援、复活、神的陨落与最终淘汰。
- 改阵营与对局队伍/胜利归属；组合牌胜利累计和插队连锁。
- 课程获取方式、数量限制、冷却起算、费用及与角色/装备的组合规则。
