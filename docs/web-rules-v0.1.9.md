# web-v0.1.9：搏击操修订

2026-10-18，负责人直接确认。候选0.2.7-p2.8／schema2／engineRevision20，继承v0.1.8。原始卡牌文档与图片保留，不把本次网页裁定写回原作。

1. basic-003／004／005搏击操Ⅰ／Ⅱ／Ⅲ基础费用分别3／4／5AP；原有扣1／2／3AP及不足转扣血不变。角色、装备、农夫三拳及牢大转肘击的现有费用规则保留。必须先付足费用，不能用将来的弃牌回复抵扣本次支付门槛。
2. 按实体ID记录本局最初获得者：首次从牌堆进入玩家手牌时确定，转交、抢夺、弃牌、洗回、再抽均不改变。无玩家曾获得的牌从牌堆直接入弃不回复。该私有归属只在新局建立，不追溯旧局。
3. 搏击操实体牌每次进入弃牌堆，最初获得者存活则通过现有AP增加流程回复1AP；阵亡不回复。主动使用、转换、被反制、免费响应、超限／水域弃牌、上交、淘汰清理均按物理实体入弃触发。转手、进入结算区及从弃牌堆洗回都不触发；同一次入弃只触发一次，后续再次入弃可再次触发。
4. 被搏击操指定的玩家，在原10秒攻击响应窗口内，可从手牌打出严格更高等级的搏击操。Ⅰ可用Ⅱ／Ⅲ响应，Ⅱ可用Ⅲ，Ⅲ无更高等级。此响应不消耗AP，可在0AP时使用；不新增独立时限，不改变现有反制链。
5. 成功响应仅抵消该父牌对自己的扣AP及AP不足转扣血，不发动响应牌攻击、不影响其他目标，不消耗主动出牌次数／农夫三拳免费出牌效果；实体牌进入弃牌堆仍触发第3条，其回复可能归属于另一位最初获得者。

旧v0.1.8及更早游戏、已开始选角均保持保存版本和原规则，不伪造历史获得者。新建选角使用v0.1.9。000—019迁移不改写，020新增版本与函数兼容分支。
