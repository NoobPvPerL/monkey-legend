## 共用结算约定（建议）

- “整轮”是所有存活玩家轮流行动一次；“个人回合”是某位玩家自己的行动时段。
- 分别保存角色固有归属、本局当前阵营、队伍。2v2的中立选中后按Q1归属所选队伍；FFA队伍仍为个人，当前阵营初始沿用角色固有归属。阵营与水生资格独立，不能把加入帝汶队的中立变成水生。
- 新增可选技能窗口统一10秒；超时视为放弃。需要被转走手牌的持有者选择牌，也给10秒；超时按实体ID升序取足。窗口暂停主行动计时，结束后恢复剩余时间，不重置60秒。重连不重抽、不续期。
- 成功主动出牌仍按已确认规则立即重置60秒，之后即使被反制也不追溯撤销本次计时重置；单独发动技能、掷骰、移动不刷新。攻击牌没有每回合张数限制。
- 大体顺序：验证目标与禁止事项 → 扣费并提交牌 → 反制窗口 → 普通防御／命中 → 效果与伤害 → 淘汰清理、资源转移和后续技能 → 最终胜负。反制某张响应牌时，先完成该响应牌自己的窗口再返回父牌。
- 免疫按效果来源和对象判断，不能把普通卡牌、角色技能、装备能力、地点和环境混成同一类。群体效果仅跳过免疫者，其他目标继续。
- 所有新增伤害默认可被护盾抵挡；只有明确裁定为真伤／直接生命流失的效果例外。以下QB和谢bro的1伤都按普通伤害处理。
- 每个原始牌／技能／位移拥有一次结算编号。同一触发技能对同一编号不得因自己的后续效果无限触发；具体次数以下各节为准。没有合法目标就不弹窗口，不能通过无效点击续时。

## Q2：反制、免疫与追击

### 2a · easy：太简单了

建议：全地图反制一张已经合法提交、尚未结算的基础牌。自己、队友、敌人的牌都可反制；攻击、锦囊、食物、响应牌、装配中的装备／坐骑均包含。不能反制已经装备的持续能力、角色技能、地点或环境。

1. 出牌者先支付正常费用并交出实体牌，再询问easy；该牌尚未进入普通防御／掷命中骰。无论反制结果如何，已付AP不退。
2. easy每次支付1AP，掷d6；3—6成功，全牌失效；1—2失败。成功时群体牌整张取消，装备不装上、食物不治疗，实体进入弃牌堆。
3. 失败后可对同一张牌再付1AP尝试，没有每回合次数限制。**这一张牌共用同一个10秒窗口，失败不重新计时。** 没有AP、主动放弃或到时即继续结算。
4. 普通防御牌也可被easy反制；防御失效则原攻击继续。原攻击上已关闭的easy窗口不重开。技能本身不是一张牌，不能再反制这次技能判定。
5. 免疫已使某玩家不受影响时，不为该玩家开启无意义的个人防御；easy若仍有AP，仍可为其他目标／卡牌整体发动反制。

例：对手打出2AP外星人，easy失败两次、第三次成功：对手失去原2AP及卡牌，easy共付3AP，治疗不发生。

### 2b · QB：根正苗红／纯菜

- 建民词条牌对QB本人无效，QB不能使用建民牌，包括主动、响应和装配；不禁止其持有、弃掉或作为转换素材交出。转换后按新身份检查，不保留素材的原建民效果。
- QB使其他存活角色**实际减少HP**后，可免费发动一次纯菜。每张原始牌／独立技能，对每个受伤目标最多一次；群体伤害可依行动顺序分别问。
- d6为3—6：原受伤目标再受1伤；1—2：QB自己受1伤。目标已淘汰、QB已淘汰、护盾完全挡住原伤害时不触发。
- 此次追加伤害／失败自伤不再触发纯菜。纯粹扣AP、对自己造成伤害、环境伤害不触发。其他受伤技能仍可按各自条件响应。
- 纯菜属于主动角色技能：梅梅涛／谢bro等不合法目标直接跳过；不能以伤后追加为由绕过主动技免疫。

### 2c · 北帝汶：北鄙／真正的帝汶

**推荐解释：本人以外，当前阵营不是机械猴子的玩家所使用的牌，对北帝汶无效。** 不是按“帝汶／外星／普通”卡牌词条判断；中立在2v2选入机械队后，其出牌可影响北帝汶。

- 自己使用的牌正常对自己生效。其他非机械玩家的攻击、取牌、换位、恢复等牌面效果均不能影响北帝汶；队友有益牌也受此限制。群体牌只跳过北帝汶。
- 属于“效果无效”而非一概禁止指定：合法提交后扣费不退，结算时跳过北帝汶。若某牌必须先有可执行的交换／复活等目标，仍遵守该牌基本合法性。
- 装备／持续牌对他人的后续效果，记录原出牌者及出牌时阵营快照，按同一来源判断；装备失去／转手后的新使用另起记录。角色技能、地点和环境不由北鄙免疫。
- 每张牌提交时冻结出牌者阵营，避免被该牌自己的改阵营效果改变免疫答案。未来化猴／化汶只影响之后提交的牌。
- 帝汶词条牌的**正数出牌／装配AP费用自动降到0**，无需先发动、无次数上限；响应牌适用。牌内额外发动技能、转移AP、X投入不免；负费用收益不因“免费”翻倍。

选择这个解释的理由：现有76种基础牌没有完整的“专门针对非机械猴子”标签表，按来源阵营可以得到统一可执行规则。代价是它改写了“针对”的字面对象，且FFA中多数中立角色的牌无法影响北帝汶；**这项尤其需要负责人审阅，不能当作已确认原意。**

### 2d · 梅梅涛／谢bro：技能免疫边界

| 效果 | 梅梅涛 | 谢bro |
|---|---|---|
| 其他角色主动技能直接作用于本人，包括有益效果／主动追击 | 免疫 | 免疫 |
| 其他角色被动／锁定技能直接作用于本人，包括撞飞 | 免疫 | 正常生效 |
| 群体角色技能 | 只跳过本人 | 主动技能跳过本人；被动／锁定照常 |
| 普通牌本体、装备／坐骑能力、地点／环境 | 无他人角色技能关联才生效；有关联则整份无效 | 正常生效 |
| 自身技能维持、发动以及对别人产生效果 | 正常执行自身规则 | 正常执行自身规则 |

- 梅梅涛“普通人”作为角色描述，不拿来关闭其“创始人”；免疫不抹掉别人的整套技能。只要本次作用包含他人角色技能修饰，对梅梅涛的整份效果无效，不保留卡牌基础部分；仅历史摸牌来源不追溯。
- 谢bro连队友主动帮助也不能接受；西帝汶带人、QB追击、东帝汶选其共同摸牌等均不能以其为对象。自身阎王薄对别人可正常发动。
- 区分“主动触发”和“发生在别人的回合”：主动技能即使是受伤后询问发动，仍为主动；牌面被动／锁定技能不会因弹了一个选择框就变成主动。
- easy反制的对象是牌，不是角色本人；两者的角色技能免疫不能保护自己打出的牌免遭easy反制。反过来，反制是取消牌本体，梅梅涛也不会因此强行保留该牌对自己的部分。

## Q3：行动、位移、即时转移

### 3a · JJ：懒得喷／没救了

建议懒得喷在自己的自由行动阶段发动，**0AP、每个人回合一次**，可以在0AP时发动。效果分两段：

1. 免费行动至当前个人回合结束：出牌、基础移动、正数固定费用角色技能／装备技能免费；仍须满足时机、次数、手牌与落点。飞船的至少1AP门槛作为固定费用类门槛一并豁免，但仍限一次。
2. 暴露目标从发动持续到下一个个人回合开始之前；即使下回合跳过行动，也先到期。淘汰时清除。

免费不等于凭空产生AP：X费用仍须实际投入X；“转给他人／扣光自己AP／比较AP”仍按真实资源；通校仍至少1AP且耗尽现有AP。不免费复制卡牌，不额外增加基础移动次数。技能发动本身不刷新60秒。

暴露目标建议如下：

- 其他玩家打出以角色为对象的主动牌时，**在原目标之外强制追加JJ一次**。原目标可为自己或队友；JJ忽略距离与敌我限制。单体因此可影响原目标+JJ，不挤掉原目标，也不重复算两次JJ。
- 攻击、移牌／取牌、治疗均适用；自用食物也给JJ追加同一治疗／附带效果，但各自角色禁疗照常。涉及交换位置等不能自然复制的单体效果，原目标先结算，再由出牌者与JJ结算一次，整个顺序固定并显示预览。
- 只对原牌可适用的对象追加：装备／坐骑只装给原使用者，不复制给JJ；防御／反制牌仍须满足原响应条件，不能凭JJ暴露就挡无关攻击。非角色目标牌不增加一份地形或召唤物。
- 不能绕过真正的不可选／免疫／离场状态，也不能把出牌者自己的JJ当作别人再追加。后续技能和地点能力不属于“所有牌”。

没救了建议：JJ直接造成的致命伤害不打开临死救援窗口，照常淘汰。**不一并禁止以后用紫檀木复活**；救治与淘汰后复活分开。JJ造成的卡牌／角色技能伤害计入，环境、别人反伤不算JJ致命来源；后续装备伤害来源规则在阶段四接入。

### 3b · 牢大：主动肘击／指点江山

- 真肘击basic-002在自己的自由行动阶段可主动使用，0AP，选同一地区的一名其他存活角色；允许队友，不能自己打自己。正常防御响应的原肘击不改成本次主动位移效果。
- 任意一张手牌可转换为这次主动肘击，**总价2AP**，不再付素材牌面费用。素材只有肘击效果，无原食物、装备或锦囊收益。主动用牌没有额外每回合次数限制。
- 主动肘击是普通词条卡牌，可被easy反制及适用的防御牌抵挡；一旦整张抵挡，伤害和位移一起取消。真肘击的角色赋予部分视作锁定强化；指点江山转换属于主动技，不能对谢bro发动；梅梅涛免疫这两种角色赋予的主动攻击效果。
- 成功结算：目标先受1伤；若淘汰，牢大传送到目标原格。若存活，牢大选上下左右一个方向，把目标撞开**1格**，同时传送到目标原格，不允许重叠。
- 可用方向要求目标邻格为空、可进入，遵守封闭农场、禁水装备等规则；不连锁推人。没有可用方向则只造成伤害，双方不动。护盾挡住1伤不阻止未被反制的位移。
- 选择方向在出牌前预览；因后续反应使所选方向失效时，给10秒重选，超时取按上右下左顺序的首个合法方向；全部非法按原地处理。落水弃牌和环境连续受伤重置按阶段二执行。

### 3c · 西帝汶：方向感／拖泥带水

方向感建议仅改变**自主基础移动**，不扭转飞船、通校、卡牌传送或别人施加的强制位移。

- 开始基础移动先声明上／下／左／右，再由数据库掷方向d6；偶数原方向，奇数反方向。步数仍用现有独立的1—3步判定。
- 这次沿最终方向直行，不能中途拐弯；可以提前结束。撞到边界、占用、山洞或禁止进入地块按现有移动规则停止；不能要求反复掷到想要的方向。
- 掷骰后本回合移动次数已用。实际未走可取消不扣AP，走过后结束／超时按既有规则扣费；水生直线越水仍按阶段二处理。

拖泥带水建议0AP，**每次西帝汶自身发生一段完整位移，最多带1人**：

- 一段基础移动整个路径算一次，飞船／通校／卡牌传送或被撞飞各算一次。打牌、摸牌、受伤但自己位置未变，不凭空创造带人位移。
- 带人对象取西帝汶起点四向相邻格上的一名其他存活角色，敌友均可；西帝汶选人，不要求敌人同意。谢bro／梅梅涛按主动技免疫排除。
- 西帝汶先完成自身位移，再将同行者传送到其**终点的一个四向相邻空格**，由西帝汶选择。同行者不得与其重叠，不占同行者自己的基础移动次数，也不另扣同行者AP。
- 自主位移可在起步前选同行者；强制位移则按起点快照，在位移完成后提供10秒选择。同行者在此期间已淘汰、已被其他效果移走、或终点无合法邻格，取消带人，原位移保留。
- 同行者使用自己的水生／装备限制，落水照常选弃牌；不复制西帝汶的水生资格。只判断传送落点，没有虚构中途碰撞。带人产生的位移不再次发动拖泥带水，避免自我递归。

### 3d · 晓虫：还有声音／整理着装

两项建议均为**0AP、条件满足立即强制处理、无次数上限**；不要求晓虫每次点发动，否则“立刻”会被可选窗口稀释。这是一项对“主动技”标签的明确执行补充。

手牌：

- 晓虫存活时，每次独立的抽牌／拿牌／转牌或伤害与淘汰清理完成后，检查受影响的其他存活角色；上限仍为floor(当前HP)。正溢出全部转给晓虫，而不是等对方结束弃牌。
- 超出N张，由原持有人选哪N张，10秒超时取实体ID最小的N张；晓虫不能提前看对方隐藏手牌选牌。只有交牌结果对双方可见，其他玩家只见数量，观战按既有全手牌权限。
- 同时多人超限按本局固定行动顺序逐个处理。淘汰者先按淘汰规则清空手牌，不从死亡弃牌中抢牌。晓虫自己的超限不再吸回自己，仍在自己结束时按通则20秒弃牌。
- 开局4人发牌作为一个批次完成，随后检查一次，避免按发牌先后偷牌。例如跑者3HP拿4张，会交1张；晓虫自身3HP拿4张不自己触发。此时还没开始行动计时。
- 这是晓虫对普通“行动中允许暂时超手牌”规则的角色例外；没有晓虫、晓虫死亡或技能无法影响该目标时，原通则不变。谢bro和梅梅涛均免疫这项主动角色技能。

AP：

- 不改全局无硬上限，给本技能设**7AP收取线**。仅对其他角色的一次AP增加计算：若增加前为B，本次增加G，收取量为`min(G, max(0, B+G-7))`；对方减少该量，晓虫增加同量。
- 因为只收新增部分，不追溯收走对方先前已有的超7AP。一次AP转移完成后不再次因晓虫自身超限触发。没有AP增加的受伤／移动等事件，不重新扫描旧余额。
- 例：4+3=7，收0；5+8=13，收6，对方剩7；10+2=12，收2，对方保留原10。晓虫获得6后可从5到11，不裁剪。
- 跑者补到6、尚德荟加到7不受影响；咖啡、头锤、肘击等新增AP会检查。梅梅涛／谢bro免疫收取，余额可高于7；这也体现7是技能线而非全局上限。
- 手牌和AP同一事件增加时，先AP，再手牌；角色淘汰清理完成后才判断晓虫是否存活。AP转移公开数值，无选择窗口。

推荐7而非5，是为了保留现有4+3=7的普通补充与跑者6AP设计。承汉骑等“无上限”牌如何抵抗收取，仍在阶段四装备适配时单列；本稿不提前认定其费用和全部能力。

## Q4：回合开始、特殊胜利及新牌依赖

### 4a · 东帝汶：领袖风范

建议在**自己每个个人回合开始时**可发动一次，0AP，全地图，无需实际进入自由行动阶段。顺序为现有回合开始资源／常规摸牌之后、主行动计时之前。

- 选一名其他存活角色，双方各摸1张；或者从一名有手牌的其他存活角色随机拿1张。
- 敌友都可选，不可自己选自己。共同摸牌的对象必须可受主动技影响；随机取牌同样不能选梅梅涛／谢bro。没有合法目标可放弃。
- 拿牌由数据库从对方手牌均匀随机，不能浏览隐藏手牌再挑。自己没手牌仍可发动；选择偷牌时目标没牌则不合法，不能用空目标刷计时。
- 合并一个10秒窗口完成“放弃／共同摸牌+目标／取牌+目标”，超时放弃；发生晓虫溢出时先结完再开始主行动。

### 4b · 东帝汶／应豪：组合胜利

| 角色 | 本局累计各至少一次的实际牌ID |
|---|---|
| 东帝汶 | 咖啡basic-015、橡胶basic-016、紫檀木basic-037 |
| 应豪 | 外星人basic-046、阿萨姆basic-041、营养快线basic-047 |

- 整局累计，不要求同一人、同一轮或连续打出；公开显示三格进度。2v2按出牌时所属队伍记账，FFA只记本人，不能和同家族的其他敌人拼单。
- 只计**以该ID实际合法使用且未整张反制**的牌；弃牌、缴牌、拿来转换成肘击、非法请求不算。伤害没命中、护盾挡完、治疗时满血等零收益，仍算成功用过；个别目标免疫也不抹掉整张牌的使用记录。
- 各卡牌自己的基本目标／时机仍须满足。没有可复活者不能空打紫檀木凑组合；复活资格、血量和费用不在本稿偷偷补齐。
- 角色本人必须存活且仍属于该队，组合齐全才生效。死亡不清旧进度，但其队友不能在其死亡期间靠此被动获胜；若以后合法复活，恢复检查。角色不在本局，普通玩家凑齐也不触发。
- 未来改变阵营／队伍：已打出的记录留在原出牌队，不能随角色搬走或复制；切换后新牌记新队。FFA即使改变角色阵营，仍独立记账，不自动组队。改阵营是否连带改队由阶段四另行裁定。
- 每张牌及其反制／追击／淘汰／转移全部结算完后统一检查：先普通生存胜负；尚未结束再查组合。若同一结算确实出现两个不同队同时满足组合，判平局并记录原因，不按网络请求先后抢胜。
- 原始卡牌效果和东帝汶“克星”不会删去。假原始人尚未入本批，不因为被引用就追加角色；日后其位移能力接入时，东帝汶存活则保护当前本队成员。

### 4c · 应豪：不可阻挡／来玩

不可阻挡建议只在**自主基础移动逐格走路**时触发，不把传送起终点之间画成虚拟冲撞路径：

- 即将进入其他存活玩家占据的格时，沿本次进入方向把对方推到该直线最远合法空格。扫描到棋盘边缘、其他占位或禁止进入格的前一格即止；不连锁推第三人。
- 山洞可以作为空的最终格，但进入即停；封闭农场／占座封锁／目标禁水等适用目标自身的进入限制。无任何腾位空间，则应豪该步不能走，不造成额外伤害。
- 梅梅涛免疫角色锁定技撞飞，挡住路径；谢bro只免主动技，因此可被这项锁定技推动。队友也能被推，不因同队免疫。
- 推动成功后应豪进入被腾空的格，正常消耗自己的这一步；对方不付基础移动AP，但跨入连续水段照常弃牌。被推路径逐格记录，换区立即重置环境连续伤害，不能只看最终格。
- 一格移动只推一名原占位者；同一原子步中完成腾位和进入，不出现永久重叠。后续带人／受位移技能另排队；同一位移结算不得自我循环。

来玩建议：应豪使用猴子游戏basic-010时，可无视教学楼／秀松苑禁用和地区距离，指定**全图1—3名其他敌人**；四人2v2实际上最多两名敌人。不能自选／打队友。不受默认卡牌目标人数限制，但不会自动追加本批以外人数模式。

仍支付猴子游戏2AP，按其确定后的命中规则分别判定；easy等可反制，目标免疫和美丽学子仅剩1张手牌的群体保护仍生效。地理限制解除不解除隐身／离场／不可选限制。猴子游戏的通用判定参数属于阶段四，不能拿此建议擅自改当前吸血／躲避球的已确认命中率。

### 4d · 谢bro：阎王薄

- 每张未被整张取消、实际进入猴子游戏结算的卡牌，最多发动一次，0AP。不是每个参与者各免费打一次。

- 此次伤害不是又使用了一次猴子游戏，不会再次触发阎王薄；其他正常受伤技能按各自规则执行。
