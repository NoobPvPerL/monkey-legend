## 2. 区域邻接

两个不同区域存在一对正交相邻边界格即相邻；无须玩家站在边界。由上表生成，不手写第二套判定。共15区域，教学楼和山洞各3格，其余各2格；每个区域正交连通。首次实现须验证邻接对称且无自环。

格距为曼哈顿距离；例如 r2c3→r3c5 = 3。两个角色同区域并不代表格距0。攻击严格按卡牌的区域范围，土豆技能按格距。普通角色占位只限制最终落点，不改变区域邻接或攻击距离。

## 3. 移动与地形状态

每个人回合一次基础移动，付1AP后d6决定1/2/3步额度；先掷后选路，可提前停。完整路径必须能停空格，允许经过人，不允许越界/斜行。处理中停在占用格时不能出牌，超时恢复最近空落点，详见W-03/W-10。

当前地形与地点ID分开；安全区是第三维状态。未来改地形不能更名地点、消除毒圈或改变已完成效果。首版没有地形变更牌和命令。

出生四格互不重叠。没有重选出生区或随机挑空位；无效配置须拒绝，不临时搬走角色。
