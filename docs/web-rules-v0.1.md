## 1. 范围、身份与开局（W-01）

- 仅四人各自为战、四人 2 对 2；优先桌面浏览器。本地调试与联机使用同一规则，独立客户端和私密手牌在 P2 验收。
- 首版只有本文件四个角色、十二种基础牌。无中立玩家加入、插队、神牌、课程、装备、坐骑、复活、救援、改阵营、反伤或特殊胜利；不从原始资料自动加载额外效果。
- 房间座位 S1—S4 固定。团战从六种“选两座为 A 队”的组合等概率取一，余下 B 队；角色四种排列等概率抽取，与队伍无关。各自为战无队友。
- 角色原始阵营与本局队伍分别保存。lemon 原始阵营帝汶家族，其余三个中立，依据本次成员补充；首版不据此限制队伍/胜利。
- 每人一名唯一角色，当前生命等于最大生命、护盾0、行动点5、次数清零，按地图出生格放置。所有首版生命/伤害均为整数；手牌上限公式仍为 floor(当前生命)。
- 64 张基础牌独立实体实例统一洗牌；按 S1—S4 各发连续4张，共16张。卡牌定义 ID 与实体 ID 分开，实例 ID 为“定义ID#两位份号”，例如 basic-009#01。
- 首位从四座等概率抽取，固定循环顺序从该座开始跨轮保持。实例洗牌、角色排列、分队与首位均独立随机。
- 只在完整合法开局状态下开始；缺座、重复角色、坏牌堆或无效地图必须拒绝初始化，不补默认内容。

## 2. 轮次与个人回合（W-02）

整轮是所有存活玩家依固定顺序各行动一次；首版没有插队。中途淘汰者跳过，原顺序不重排。第1轮同样执行轮开始流程。

整轮开始：
1. 刷新所有“每整轮一次”技能与 lemon 攻击者奖励计数。
2. 对每个存活玩家：行动点 <5 则加3，否则不加；跨轮保留，无统一硬上限。
3. 应用本轮安全区与上轮预告轰炸，按当前位置计算环境伤害批次。
4. 处理伤害、淘汰、受伤触发与胜负，再进入个人回合。

个人回合：
1. 跑者若行动点 <6，补至6；更高不变。
2. 第1轮跳过常规抽牌；第2轮起仅当前玩家抽2。
3. 美丽学子可额外摸1。
4. 当前玩家可交替进行基础移动、攻击、补给，也可主动结束。
5. 美丽学子可额外摸1，再由当前玩家自选弃牌至 floor(当前生命)。
6. 清空本个人回合移动/攻击计数，交给下一名存活者。

所有存活者本轮行动结束后：若为第12轮，强制终局；否则公开下轮安全区，并在第2轮及以后抽取、预告下一轮轰炸，再开始下一轮。没有第13轮。
初始安全区与完整缩圈表开局可见。第1轮结束不预告轰炸，第2轮开始也没有轰炸。

普通补牌后、他人回合受伤后均不即时执行普通弃牌；只有自己结束阶段检查。技能摸牌可暂时超限。行动点不足时仍可免费响应肘击或结束回合。

## 3. 地图、距离与移动（W-03）

准确32格见 [地图表](map-spec.md)。格坐标 r1c1—r4c8；同名地点是一个区域，共15个区域。淘安泽、红素洋四格水域，其他陆地，无墙或其他阻挡。

- 格子距离 = 行差绝对值 + 列差绝对值；不走斜线、不因水域增加攻击距离。
- 相同区域是地点 ID 相同；相邻区域是存在一对上下左右相接的边界格，不要求两名角色所在格彼此相邻。相邻不包含同区域，标注“同/相邻”的范围取两者并集。
- 基础移动每个人回合最多一次。支付1行动点且消耗次数后掷一个均匀 d6：1—2/3—4/5—6分别获得1/2/3步移动额度；再逐步提交正交相邻格，可提前结束，包括原地放弃；失败判定或放弃不退款。
- 从当前格进入陆地耗1步，进入水域耗2步；起始格不收费。可经过其他角色，不能结束在占用格。经过占用格时记录为移动中的位置、暂停出牌/响应以外操作，必须在剩余额度内离开；没有空落点的完整路径不能提交。超时退回最近已确认的空格，未用额度作废。
- 只有剩余额度足够且最终能停到空格的路径才合法；离开棋盘、斜移、二次基础移动、传送占用/水域格均拒绝，不改变任何状态。
- 土豆传送与基础移动次数无关；可传送至距离≤3的空陆地，包含毒圈格，但须提示危险。
- 位置、地形、队伍或手牌状态每次合法效果结算后重算可操作目标；服务器最终复核。已提交攻击的目标在指定时锁定；首版受伤传送发生在该牌所有目标伤害之后，不取消已受伤害。
- 地点 ID、地形、安全状态分别保存。未来地形牌须另写规则版本；首版预留更新入口，不开放未定义的地形命令。地形变化不更名地点、不清除毒圈、不回溯已结算效果。

- 攻击只能选择存活敌人，不能自己/队友。补给只对自己；角色技能的队友不含自己，明确写“自己和队友”才包含自己。
- 一个人回合最多使用两张攻击牌。提交并支付后即计数，被抵消、未命中也占一次；群体牌不因目标多计多次。响应不计攻击次数。

- 多目标必须不同，受响应影响后只结算剩余目标。无重掷、改骰、额外暴击、伤害穿透或未列出的牌面效果。

## 5. 四个角色（W-05）

| 定义ID/角色 | 最大生命 | 出生 | 原始阵营 | 首版完整能力 |
|---|---:|---|---|---|
| character-004 lemon | 5 | r4c1 | 帝汶家族 | 嘲讽、承伤奖励与支援，见下 |
| character-027 美丽学子 | 4 | r2c3 | 中立 | 每个自己回合开始/结束各可额外摸1；恰1手牌时不能被群体攻击指定；食物回血0 |
| character-031 跑者 | 3 | r1c1 | 中立 | 自己回合开始AP不足6补6；受伤恢复，见下 |
| character-037 土豆 | 5 | r2c5 | 中立 | 每整轮一次，受伤且存活后可免费传送到距离≤3的空陆地 |

lemon：
- 敌人的单体攻击若 lemon 是该牌合法目标，必须选 lemon。适用于全图单体搏击操；不影响群体牌、补给或响应肘击。每局只有一个 lemon，不存在多嘲讽并列。
- 每名敌人每整轮首次用攻击牌对 lemon 造成实际生命损失后可摸1。以“lemon、攻击者、轮号”记次数；护盾全挡不触发，不接受环境、响应或自己付生命作为奖励来源。
- lemon 因任何本版伤害实际失血且存活后，每整轮可支付1行动点，使自己及存活队友各摸1。各自为战仅自己摸1；无多点伤害多次触发。
- 同次伤害先处理攻击者奖励，再处理 lemon 支援。拒绝奖励/支援不消耗各自次数；同一伤害的窗口关闭后不能回头发动，但后续伤害仍可满足未用次数。

跑者：任何本版伤害失血且存活后，每整轮最多一次恢复判定。拥有≥2行动点才可选择发动，发动即消耗次数；d6为4—6后可支付2点回复1，失败不扣点，成功也可放弃付费。判定及付费结果公开。更高行动点不因回合刷新被裁剪。

土豆：伤害护盾全挡、没有合法落点或已经死亡时不能发动。确认合法传送并执行才耗次数；放弃可留给后续伤害。不会触发新的受伤，也不递归触发自己。

所有受伤技能必须是“实际生命损失>0且本批次后存活”。lemon支援、跑者恢复、土豆传送可由环境伤害触发；lemon攻击者奖励只由敌方攻击牌触发。跨个人回合的技能次数只在整轮开始刷新。

## 6. 响应、伤害与事件顺序（W-06）

单次攻击：
1. 校验操作者、阶段、手牌、费用、次数、目标、范围、嘲讽和指定时免疫。
2. 扣费用、移出攻击实体到结算区、增加攻击计数。
3. 按本局固定循环顺序逐一收集受影响者的响应；响应费用立即支付，响应牌移入结算区。全部响应确定后再结算牌效。
4. 需要骰子的牌掷一次d6；响应已取消全部目标时不掷骰。头锤被肘击时，原攻击取消，改结算肘击反向效果。
5. 依该牌完整效果计算各目标行动点变化与伤害，所有目标的伤害作为同批次应用；群体牌不因先处理谁产生额外优势。
6. 同批次生命0者同时淘汰，清空AP、护盾，手牌进入弃牌；不允许救援、复活、结束摸牌或受伤技能自救。
7. 存活攻击者处理吸血治疗，再按本局固定循环顺序处理所有存活受伤者的触发；lemon的奖励在其支援之前。一次技能效果原子完成后再开启下一个选择，不能插入普通出牌。
8. 结算区攻击与响应牌入弃牌堆，检查胜负；未结束则恢复当前玩家操作。响应伤害杀死当前行动者时，完成清理/触发/胜负后跳过其剩余回合，不执行其结束技能/弃牌。

环境：轮开始的位置快照同时计算所有人的毒圈+轰炸伤害，合计为一个环境批次；所有淘汰先于受伤触发。之后传送不重算本轮伤害，不在新落点立即再扣一遍；下一轮才再次计算。

普通补给：支付并暂存卡牌 → 治疗 → 护盾或摸牌 → 弃入弃牌堆 → 胜负/状态校验。正在结算的任何牌不能被本次摸牌抽回。
非伤害损失行动点不触发“受伤”。无生命支付/持续状态等未列出的首版效果。

## 7. 牌堆、可见性、随机与更新（W-07）

- 一个64实体的抽牌堆、公共弃牌堆、暂存结算区、四份私有手牌；实体在任一时刻恰属一区。角色不混入基础牌堆。
- 抽牌逐张执行，抽牌堆空时将当时全部弃牌洗为新堆；结算区与手牌不参与。两堆都空则停止，不生成牌、不负张数。
- 所有d6各面1/6；移动步数各1/3；命中/恢复成功率1/2。轰炸按候选区域等概率，不按区域格数加权。洗牌使用无偏排列，正式联机由服务端产生。
- 测试可注入完整洗牌排列、分队、角色、首位、骰子和轰炸序列；它们是可复现输入，不是允许客户端指定随机结果。
- 公开角色/队伍/生命/护盾/AP/手牌数量/地图/弃牌/动作及骰子、待响应者、环境预告；手牌内容仅本人，牌堆顺序/未来骰子/随机种子不发客户端。淘汰手牌转公开弃牌。
- 距离预览只基于公开状态；客户端动画不决定规则。命令版本过旧、重复或阶段不符不能重复扣费，联机实现细节在P2验证。

## 9. 淘汰、终局与排名（W-09）

- 完整牌/环境批次及其存活者触发、清理之后检查：只余一名玩家或一支有存活者的队伍则获胜；同一批次全体淘汰则平局。团战某队全灭、另一队仍存活即可结束。
- 第12轮所有存活者行动结束，未自然决出胜负则比较：存活人数 → 剩余生命比例 → 击杀数 → 实际敌方生命伤害总量 → 仍同则平局。
- 个人存活人数为0或1，比例=当前生命/开局最大生命。团队人数=队内存活人数，比例=队员剩余生命之和/两名开局队员最大生命之和，淘汰者分子0，分母不缩小。
- 比例用整数交叉相乘精确比较，不用显示用的四舍五入百分比。团队击杀/伤害取两位成员的累计总和，成员淘汰后其历史贡献仍保留。
- 直接造成致命普通伤害的敌方玩家获得击杀，肘击反击也计；环境击杀不归任何玩家。实际伤害只计敌人真正损失的生命，不含护盾、AP、溢出；治疗不减少历史伤害。
- 提前淘汰按伤害批次先后排名，越晚越高；同批次并列。自然获胜者/队伍第一；强制终局对剩余竞争者用上述比较排序，相同并列。已全灭团队按最后成员淘汰批次排序，双方同批次全灭并列且无赢家。

## 10. 计时、断线与非法操作（W-10）

- 当前玩家个人回合预算60秒，包括开始/结束的可选摸牌和普通操作；其他玩家的响应及受伤选择窗口暂停其预算。每次选择窗口最多10秒，按服务器时钟计。
- 伤害触发中需要当前玩家本人选择时也用独立10秒窗口并暂停个人预算，避免同一选择耗两次时间。已用预算在响应结束后继续，不重新获得60秒。
- 无可选响应/技能自动跳过。选择超时视为放弃；跑者已宣告判定成功但付费选择超时则不支付、次数仍用掉。
- 行动预算用完进入结束阶段；美丽学子若尚未选择结束摸牌则视为放弃。需要弃牌时给一个10秒选择窗口；超时按定义ID升序、同定义份号升序依次弃掉超限数量，明确日志记录“超时代弃”。
- 移动选路期间预算照常计；超时按W-03结束移动再结束回合。断线不额外暂停、不自动投降，继续相同计时；重连恢复同座、状态及原剩余时限。胜负只按正常规则产生。
- 暂停、机器人、投降、房主踢人影响进行中对局均不在首版范围。非法命令不扣费、不耗次数、不重置计时；超时与命令同时到达由服务器串行事件顺序决定，过期命令拒绝。
- 若轮开始环境/触发已结束比赛，不再发行动回合；达到第12轮终局后拒绝任何新出牌。

## 11. 采用差异与验收边界

在原始通则基础上新增地图/地形、所有费用与时点裁定、角色限次、骰子、轰炸/缩圈/计时/终局。明确改动包括：角色池与队伍分开；头锤最多吸2；防御姿态覆盖所有首版攻击；搏击操ⅠⅡ单体、Ⅲ至多两人；lemon支援调整；土豆限距限次；无首版救援复活；最终六格而非旧草案两格。完整来源与差异见 [来源记录](rule-decisions.md)。

P0仅验收规则/数据规格与文档推演。20—30分钟是目标，角色/先手/出生/牌比/计时/全图AP压制与六格终局的公平性未实测。后续实现若发现缺口须记录并修订规则版本，不能宣称 P0完成就不再允许设计修改。
