# web-v0.1.8：P2真人试玩修订

2026-10-18。候选应用0.2.6-p2.7、schema2、engineRevision19。继承web-v0.1.7的16角色、76种191实体及四人FFA／2v2。负责人在本次对话批准实施；不表示此候选已经部署或真人验收。

## 工作室反馈与负责人直接确认

1. 角色技能选择统一30秒，包括easy、跑者、西帝汶、角色摸牌及转交选择；普通防御／卡牌反制、水域弃牌、装备响应等仍保持各自原时限，手牌上限弃牌20秒，选角30秒。技能选择暂停个人行动预算，结束恢复剩余预算；easy同张牌共用原截止时间，失败、报价、重连、重试不续时。
2. 来玩basic-012、樱花舞basic-014排除使用者，队友仍按原效果参与；给你加分basic-011仍包括使用者。上交不是使用，不支付所交牌费用、不发动其牌效。
3. 禁止普通移动进入或穿过有人格，包括移动过程的公开快照。应豪冲撞先把人推离、腾空后才能进入；带人、强制移动、交换、传送、复活亦不能留下重叠位置。死亡及离场者不占格。
4. 帝汶水生类别包括lemon。整段直线越水消耗1点移动步数，整次基础移动仍按起点结费，不额外扣1AP、不弃水域牌。不能普通走进并停留水格；只落延长线第一个陆地格，被占、封闭或越界即不能越水，不改落旁边。
5. 北帝汶锁定技替换旧按出牌者阵营免疫的解释。同一张牌指定北帝汶时，不得同时指定其他当前非机械猴子角色；可以同时指定合法机械猴子。也可不选北帝汶而同时指定lemon和机械猴子。按当前阵营判断，仍受卡牌敌我／数量／距离、梅梅涛及其他免疫限制。主动技正费用减免不变。

## 授权后由Codex拟定、负责人批准的边界

以下不是工作室原文逐条裁定；负责人先授权自行规划，再明确批准整份方案。

- 传送／被传送入水时，水生沿起点到落点的方向继续上岸；斜向取对应斜向延长线，第一岸格非法则位移不成立。位移不成立不留下水中位置，卡牌其他效果链继续，已成功提交的费用不退。
- 汶泽把脚下变水而无进入方向时，按最短正交距离找最近合法陆地；并列本人10秒选择、超时按格ID排序。按行动顺序处理并预留岸格，不耗AP或基础移动，不递归产生西帝汶带人。
- 生效前为所有受影响帝汶检查并预留互不重叠岸格；无法分配则该次地形变化不生效，成功提交的费用不退。
- 自动群体牌涉及北帝汶互斥时，出牌前明确选择“北帝汶及合法机械猴子”或“其他合法目标”分支。分支内保留原本全体、敌我、距离等规则，不开放任意缩减目标。
