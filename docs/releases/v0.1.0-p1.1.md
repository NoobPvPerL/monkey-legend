# P1 本地测试预发布 v0.1.0-p1.1

给项目成员的Windows x64本地测试包，游戏规则为web-v0.1.1。P1实现与开发验证已完成，正式验收仍待成员试玩和负责人确认。

## 下载与启动

1. 下载附件 **monkey-legend-0.1.0-p1.1-windows-x64.zip**。
2. 完整解压，双击 **启动游戏.cmd**。
3. 浏览器中选择模式并开局；结束测试时关闭启动窗口。

内置Node运行时，不需要安装Node/npm/Git或下载依赖。脚本会尝试打开默认浏览器；未自动打开时访问窗口显示的本机地址，默认127.0.0.1:5180，端口占用时自动更换。

仅提供一台电脑上的四座轮换；没有房间、远端联机或独立客户端隐私。Windows 10/11 x64为支持目标；目前已做同机独立解压验证，其他成员电脑仍待测试。

游戏ZIP仅包含游戏构建、16张游戏内参考图、启动服务、运行时、必要许可与版本/哈希清单，**不包含开发文档、计划、报告、测试场景或node_modules**。GitHub自动生成的Source code归档是源码，不是免安装游戏包。

## 本版内容

- 四人各自为战和2对2；四角色完整能力、12种64张实体牌。
- 32格地图、移动/响应/技能/弃牌、缩圈轰炸、计时与完整胜负结算。
- 公开日志、牌面参考、可导出/载入复现JSON。
- 修复JSON类型校验、公开攻击/弃牌信息和恢复后命令编号问题。

## 验证与反馈

87项自动测试、类型检查、生产构建、187图片与4份原始转录哈希核对通过。发布包还需逐文件哈希、独立中文/空格路径解压、移除系统Node/npm后的包内CMD启动、HTML/JS/CSS/16图及服务退出验证；实际发布结果以仓库开发日志为准。
