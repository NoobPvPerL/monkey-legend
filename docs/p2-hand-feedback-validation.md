## 实现

- 玩家与观战手牌共用use-hand-scroll.ts：鼠标左键横向拖动、普通滚轮转换为横向滚动，支持原生水平滚轮。仅溢出手牌区处理滚轮；Ctrl／Meta滚轮及无溢出不拦截。触屏沿用浏览器原生滚动。
- 拖动横向阈值6px，拖动后拦截对应鼠标点击；普通点击和键盘激活保留。捕获指针并处理松手、取消及失去捕获，拖出区域后松手也清理拖动状态；不会把浏览动作当作出牌。
- CardEffectSummary在操作区及展开弹窗显示当前规则完整牌效和本次费用；变量X与未锁定费用区别显示。转换肘击展示转换效果，原搏击操实体入弃回复仍注明；普通响应肘击保持响应牌本身文字。
- 战场动态根据公开出牌／响应日志识别牌名，使用版本目录展示完整说明；不读取他人手牌或私有报价。已公开费用及实际AP／伤害结果保留，免费高等级搏击操响应明确仅取消自己受影响部分。
- 含完整牌效的动态提示显示12秒，可手动关闭；其他提示仍4.5秒。只改本地显示时长，不暂停或延长任何对局窗口。长内容只在浮层内部滚动；手机主页面仍单屏。
