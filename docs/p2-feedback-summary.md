## 5. 地点特性

以下均来自娟巴意见的转述，保留反馈中的名称；名称尚未与地图资料统一。

| 地点 | 反馈中的效果 |
|---|---|
| 高唐农场 | 摸牌时多摸一张 |
| 操场 | 移动不消耗行动点 |
| 飞船 | 自己回合内可将 AP 清零，传送到指定位置 |
| 教学楼 | 不能使用“躲避球” |
| 秀松苑 | 不能使用“猴子游戏” |
| 办公室 | 不能被“建民”类卡牌指定为目标 |
| 云上学府 | 不能被“断水断电”指定为目标 |
| 红素洋、陶安泽 | 属于水域，适用专门通行规则 |
| 山洞 | 不进入毒圈或轰炸区；移动经过时必须停留，不能一次穿过 |
| 尚德芸 | 自己回合开始多回复一点 AP |
| XDF | 使用“食物”类牌回血时额外回复一点 |

待确认的执行细节包括：

- 高唐农场是否影响所有技能摸牌。
- 飞船传送范围、次数及 AP 为零时是否可用。
- 操场免费移动的次数限制。
- XDF 额外回血是否受角色限制影响。
- 地点名称及对应格子，包括反馈中的“陶安泽”与现有资料“淘安泽”的对应关系。

## 6. 水域、毒圈与轰炸

### 6.1 水域通行

娟巴转述：

- 非“帝蚊类”角色进入或经过水域需弃一张手牌；第二回合仍在水域时，自己回合开始再弃一张。
- “帝蚊类”角色自动越过水域，不额外消耗 AP、不弃牌，也不能停留。

待确认：角色类别名单、进入与经过的扣牌次数、无牌可弃时的处理、连续水域及越过后落点不合法的处理、“第二回合”的计数方式。

### 6.2 环境分区与停留惩罚

XRY 转述及后续补充：

- 室内逐渐进入毒圈；室外每轮随机轰炸。
- 教学楼等有建筑的地点算室内，水域、操场等算室外。
- 持续待在同一地点的毒圈或轰炸区，每轮伤害翻倍。

娟巴转述补充：山洞不进入毒圈或轰炸区。

待确认：完整室内外清单、初始伤害、翻倍方式、离开后是否重置、毒圈与轰炸是否叠加、随机候选及预告机制，以及“回合／整轮”的准确含义。

以上会明显改变当前地图、移动和环境结算，应与地点能力一起设计、验证。
