# P2 游戏反馈：好友联机版 v0.2.0-p2.1

反馈入口：[Issue #13](https://github.com/NoobPvPerL/monkey-legend/issues/13)（已开启）。

[进入在线游戏](https://monkey-legend-p2.app.workbuddy.host/) · [GitHub Release](https://github.com/NoobPvPerL/monkey-legend/releases/tag/v0.2.0-p2.1) · [规则 web-v0.1.1](https://github.com/NoobPvPerL/monkey-legend/blob/main/docs/web-rules-v0.1.md)

2026-10-16，负责人确认服务器已上线，并已完成一轮真人游玩；本主题开始收集P2联机版的问题、体验与改进建议。一轮试玩不代表所有模式、设备和边界场景都已验收。

进入网页先确认玩家名，再创建房间或输入4位房间码加入。四名玩家在线且全部准备后，由房主开始。继续原身份时使用原浏览器保存的恢复凭据；仅输入同名不能取回座位。

## 请重点反馈

1. 建房、入房、同名提示、准备与模式选择是否顺畅；是否出现进不去、假在线或状态不同步。
2. 手牌是否只对本人可见，目标选择、出牌、响应、技能、移动与弃牌是否清楚易用。
3. AP、伤害、角色技能、缩圈/轰炸、胜负及公开日志是否符合规则；说明当时模式和场景。
4. 60秒行动/10秒选择、刷新、断网重连、页面接管后，是否恢复正确座位并继续原计时。
5. 一局结束后能否保留原房间码和成员，准备后再开；房主离开、座位释放是否正常。
6. 四人游玩的实际局长、等待感、卡顿、界面负担、手机/电脑适配，以及优先改进的操作。

当前范围：四角色、12种64张基础牌，各自为战/随机2对2；神牌、课程及更多内容属于后续扩展。请区分现有功能缺陷、操作体验和新增内容建议。
