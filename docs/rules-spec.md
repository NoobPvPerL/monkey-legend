## 2. 必要状态与不变量

对局保存规则版本、模式、固定座位/首位、队伍、角色ID/原始阵营、轮号/阶段/行动者、生命/最大生命/AP/护盾、位置、牌堆/弃牌/结算区/各人手牌、移动中路径与剩余额度、响应选择、每轮技能次数、每回合攻击/移动次数、击杀/伤害/淘汰批次、当前/下轮环境、剩余时限及事件顺序。

- 64个卡牌实体始终恰属一个牌区；不混入角色或未启用定义。
- 存活生命>0，AP≥0，0≤护盾≤2；淘汰AP/护盾为0；普通AP无硬上限。
- 只有结算间空闲落点要求角色互不重叠；经过占用格属于不可插入出牌的移动中状态，超时回最近空格。
- 队伍固定，原始阵营不随队伍更名。顺序跨轮固定；所有人至多行动一次，淘汰跳过。
- 所有伤害/选择/随机结果有来源事件；同事件不重复付费或触发。
- 每次合法效果之后重算合法操作；非法/旧版本/重复命令不重复改变状态。
- 终局不可再进行操作；最高12轮，不允许因断线无限停住。
