# P2 第一批试玩操作改进与验证

日期：2026-10-16（Asia/Hong_Kong）。

状态：本地开发与验证记录；负责人正式验收、真实手机实机验证及线上更新分别记录。

## 1. 授权与范围

负责人批准今晚实现[反馈归纳](p2-feedback-summary.md)中的第一批，并要求第二批先提交[具体设计](p2-interaction-design.md)。本轮追加两项截图反馈：隐藏所有网页滚动条外观；手牌及文字纵向完整显示，允许横向滑动。

本轮功能：

- 联机主界面集中展示四名玩家、棋盘、本人手牌和操作区；压缩入口、房间与对战文字。
- 规则、历史日志、弃牌和牌面按需打开，弹窗支持Escape关闭、焦点循环及关闭后恢复焦点。
- 自己行动、响应或技能选择时突出提示；其他玩家出牌、淘汰、轮次变化提供短时提示。重复快照不重复提醒，恢复连接不重播历史攻击。
- 提示音默认关闭，通过玩家主动点击启用；播放受浏览器音频状态约束。
- 最新一次玩家动作持续显示；完整内容可在日志查看。
- 对局结束自动显示现有引擎排名，不改变自然胜利、团队、强制终局或并列规则；“再来一局”返回原房间准备，不自动替全员准备或开始。
- 全页面隐藏滚动条外观，保留触摸、滚轮及键盘滚动。手牌区仅横向滚动，卡牌高度由完整文字撑开，不裁切底部或省略效果文字。

数据库、网关、联机协议、现行规则与牌池未在第一批修改。移动结束扣费、聊天、观战和骰子/发牌动画仍处于第二批设计阶段。

## 4. 本地浏览器验收方法

- 使用仅监听127.0.0.1的临时网关及内存PGlite数据库，应用生产构建页面和现有SQL迁移。
- 一名浏览器测试玩家加三名程序测试客户端；本地程序客户端仅用于验收，不是新增游戏机器人功能。
- 通过真实入房、准备、开局和游戏命令驱动页面，没有将虚构游戏状态注入浏览器。
- 终局展示测试使用隔离数据库拥有者推进测试时钟，触发现行数据库超时和环境流程；不属于按真实时长进行的人类完整游玩。
- 未连接、写入或重新部署当前线上应用及云数据库。

已执行：

1. 玩家名确认、创建房间、四人准备与开局。
2. 各自为战中选牌、选择合法目标、确认出牌；本人AP、目标AP、攻击次数、最新动作及日志更新。
3. 双人同盟中移动按钮、合法格高亮、真实移动一步及结束移动；本轮仍按现行规则在移动开始扣费。
4. 刷新后重新确认名字，并以浏览器保存凭据恢复同一座位。
5. 规则独立窗口；Shift+Tab/Tab循环留在窗口内，Escape关闭；提示音开关状态正确切换。未以开关状态代替实际听觉验收。
6. 各自为战和双人同盟终局弹窗展示；点击“再来一局”保留房间码、四名成员，重新准备后开始新对局。
7. 多尺寸首屏、手牌完整性、滚动条隐藏、横向滚动及弹窗尺寸检查；见最终浏览器报告与截图。
