# 网页规则 web-v0.1.5：环境与试玩补丁

状态：2026-10-17本地候选，负责人在本会话直接提出五项补丁，并确认三组执行参数；随后补充跑者削弱及“AP高于6保持现状”的更正。本版属于负责人批准的网页版规则，不修改原始牌面。继承[web-v0.1.4](web-rules-v0.1.4.md)，以下为差异。

## 毒圈与轰炸

- 山洞永久不进入毒圈、轰炸候选。
- 教学楼、操场、办公室永久不进毒圈；其余11个地区均可进毒圈，包括原室外和水域地区。每整轮开始新增2个未中毒地区，最后不足2个时取剩余，最多11区，第6整轮开始全部用尽。
- 在11区全部变毒之前，教学楼、操场、办公室也不参加轰炸。轰炸候选为原室外地区去除操场，共5区；每轮末取2个不同地区，无提前预告。
- 11区全变毒后，上述3地加入原有候选，合计8区，仍每轮末取2个不同地区。其他室外候选继续保留，不改成只炸这3地。
- 同时在毒圈和轰炸范围仍按现有一次环境危险判定结算，不额外叠加两份基础伤害。连续实际失血翻倍、护盾、换区重置及农场第5轮封闭沿用前版。
- 界面保留最近一次已结算的轰炸图标，并标明“最近第N轮轰炸；本轮轮末重新抽取”。这是历史记录，不是预告，也不会在新轮开始额外造成伤害。

## 山洞野人

- 每位玩家分别统计连续在山洞结束了多少个自己的个人回合，按结束时的位置计数；主动结束和超时结束都计一次。
- 第3次扣除2AP，AP不足则扣到0，并受到1伤害；该伤害可由护盾抵挡。打完后计数归0，每连续3次再次结算。
- 中途离开山洞立即归0，回来重新累计；同属山洞地区的格子之间换位不清零。
- 在结束技能之后、手牌上限弃牌之前处理；伤害后按新HP检查手牌上限。正常受伤技能仍可触发；死亡立即清理、检测胜负，不能从同一次结算重复扣费。
- 野人属于地点事件，不是其他角色技能；梅梅涛的角色技能免疫不因此免除野人。野人淘汰不归属玩家击杀，结算显示“野人袭击”。

## 先手与防御

- 每局开局在可信数据库边界独立均匀随机选S1—S4为先手，之后仍按固定座位顺序轮转。允许连续几局碰巧同一座位，不用轮流先手代替随机。
- 玩家只能发送开始意图，不能上传首位、种子、骰子或完整状态。重复开始请求沿用原回执，不重新抽先手。
- 防御姿态不能响应躲避球；手牌中仍可保留该牌供其他合法攻击使用。原已开始版本的响应规则保留。

## 跑者

- 整轮统一AP增加阶段，跑者不获得通用的“低于5加3”。其他存活角色照旧。
- 跑者自己的个人回合开始时，AP低于6才补到6；等于或高于6保持原值，不削掉已有高AP。
- 之后按已确认顺序处理地点加成：尚德荟首轮之后再+1。例如AP9保持9，再在尚德荟加到10；其他地点保持9。
- 受伤恢复技能的骰子、费用和次数不改。旧版仍执行各自保存版本的统一加点与个人回合补充。

## 版本与阶段三边界

本地候选0.2.3-p2.4，schema2，engineRevision14，增量[014_classic_feedback_patch.sql](../database/migrations/014_classic_feedback_patch.sql)。新版新局用v0.1.5，v0.1.1—v0.1.4旧局不重建；旧v0.1.4的图标显示可从公开历史恢复，不改旧局伤害规则。

负责人同时批准[阶段三角色方案](p2-stage3-skill-proposal.md)，并加强梅梅涛最高优先级：当前作用于他的整份效果只要涉及其他角色技能的费用、目标、伤害、位移、转换等修饰均无效；仅过去通过技能摸到的手牌，不永久带免疫标签。免疫规则优先于角色特例，装备效果若与他人角色技能有关也不能绕过。

本轮加入并对照验证TS／SQL免疫边界，但16角色完整技能、选角房间流程及阶段四依赖仍在后续；当前正式运行池保持已实现4角色、12种64实体牌。不能把单独边界函数当作梅梅涛或16角色已开放。

之前交付的阶段二源码／SQL ZIP为独立冻结快照，不包含本补丁。本地修改不代表已有云端部署；安装新应用前需配套数据库014及就绪检查。
